# MOS NAS Card

> [!IMPORTANT]
> **This repository has moved.** The card is now developed inside the
> [MOS NAS integration](https://github.com/anym001/ha-mos), in
> [`frontend/`](https://github.com/anym001/ha-mos/tree/main/frontend), and ships with it. This
> repository is archived and receives no further updates.

- **Documentation and options:**
  [frontend/README.md](https://github.com/anym001/ha-mos/blob/main/frontend/README.md)
- **Issues:** [anym001/ha-mos](https://github.com/anym001/ha-mos/issues)
- **Installing:** install MOS NAS from the HACS default store — the card comes with it, there is
  nothing to download separately. If you still have this card from HACS or as a manual resource,
  remove that copy, as described in the
  [integration's README](https://github.com/anym001/ha-mos#companion-card).

The releases up to v0.3.1 and this repository's history stay available here.
